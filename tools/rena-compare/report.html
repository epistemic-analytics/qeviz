Both sides plot the same ena.set. Each renderer's output is read back and compared against values computed directly from the set, in model space: nodes from rotation$nodes, networks from colMeans(line.weights), means and t.test CIs from points. For ordered (ONA) models, edges are matched by direction (source → the node the wide end sits on). qeviz is drawn with scale-points="false" to match the reference renderer, which does not rescale points. WARN rows describe how the plot is drawn (like relative line widths), not the data.
